## 4. Análise de Segurança (ADR-019 Threat Model + ADR-017 Argon2id)

### 4.1 Threat Model STRIDE (SPEC-017/022 + ADR-019)

| Ameaça | Controle Obrigatório | Spec/Teste | Status |
|--------|---------------------|------------|--------|
| **Spoofing** | Argon2id (m=19456, t=2, p=1) + rate limit login | SPEC-017 AC-03, ST-01 | ✅ Definido |
| **Tampering** | `require_owner` middleware (server-side, 404 cross-user) | SPEC-017 AC-07, ST-03 | ✅ Definido |
| **Repudiation** | `account_lifecycle_events` imutável + hash encadeado | SPEC-022 AC-02 | ✅ Definido |
| **Info Disclosure** | Logs sanitizados (CP-2); IDOR tests; enumeração HMAC timing | SPEC-015 CP-2, ST-08, ST-09 | ✅ Definido |
| **DoS** | Rate limits (login 5/min/IP, reset 3/h, API 100/min) | SPEC-017 §7, ST-01 | ✅ Definido |
| **Elevation** | Session regeneration; CSRF double-submit; alias rotation atômica | SPEC-017 AC-05/06/08/09, ST-02/04/05/10 | ✅ Definido |

### 4.2 Controles de Implementação (ADR-019 §4)

| Controle | Especificação | Teste Obrigatório |
|----------|---------------|-------------------|
| **Argon2id** | `argon2-cffi` m=19456, t=2, p=1; `hash_password`/`verify_password` | ST-01 (brute force), timing attack |
| **Sessão** | Token 32 bytes; SHA256(token+pepper); HttpOnly/Secure/SameSite=Lax; sliding 24h; regeneração login | ST-02 (session fixation) |
| **Reset Senha** | TTL 1h; single-use (`used_at`); rate limit 3/h; SMTP local | ST-06 (reuse), ST-07 (expiry) |
| **Aliases HMAC** | `lookup_hmac = HMAC-SHA256(pepper, normalized)`; pepper 90d; unicidade | ST-08 (timing attack) |
| **Owner Check** | Middleware `require_owner` em 100% rotas recurso; 404 não 403 | ST-03 (IDOR cross-user) |
| **CSRF** | Double-submit cookie + header `X-CSRF-Token`; exceção `/v1/auth/` | ST-04 (missing), ST-05 (invalid) |
| **Rate Limiting** | Tabela §7 ADR-019; `slowapi` ou custom | ST-01 (brute force) |
| **Dados Bancários** | `pgcrypto` AES-256-GCM DEK por usuário; snapshot descriptografa | ST-09 (log sanitization) |

### 4.3 10 Testes de Segurança Obrigatórios (ST-01..ST-10)

| ID | Teste | Critério de Aceite | Spec |
|----|-------|-------------------|------|
| **ST-01** | Brute force login | 6ª tentativa bloqueia 15min; log segurança | SPEC-017 |
| **ST-02** | Session fixation | Login regenera session ID; anterior inválida | SPEC-017 |
| **ST-03** | IDOR cross-user | User A não acessa recursos User B (404) | SPEC-017/022 |
| **ST-04** | CSRF token missing | POST mutável sem header → 403 | SPEC-017 |
| **ST-05** | CSRF token invalid | Header token errado → 403 | SPEC-017 |
| **ST-06** | Reset token reuse | Token usado 1x; 2ª tentativa → 400 | SPEC-017 |
| **ST-07** | Reset token expiry | Token > 1h → 400 | SPEC-017 |
| **ST-08** | Enumeração timing | `lookup_hmac` tempo constante (±5ms) | SPEC-017 |
| **ST-09** | Log sanitization | Logs sem PII, valores, corpo (CP-2) | SPEC-015 |
| **ST-10** | Alias rotation atomic | Update CNPJ + rotate alias mesma transação | SPEC-017/018 |
